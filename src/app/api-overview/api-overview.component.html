LunarChain Platform Overview

LunarChain is a graph-native threat intelligence platform built to give analysts, applications, and agentic systems a shared intelligence model. The platform combines a public landing/docs site, an authenticated analyst frontend, a FastAPI backend, LunarGraph as the canonical intelligence store, and LunarMCP as the guarded read-only agent interface over that graph.

High-level architecture

Agentic Access

MCP and Agent Workflows

LunarMCP is the read-only agent layer over LunarGraph. Its job is to give agents a stable contract for bootstrap context, schema awareness, relationship guidance, and bounded query execution. It is not a server-side natural-language-to-AQL translator.

What MCP is for

Expose the graph to AI agents through a controlled, reusable interface rather than through ad-hoc backend debug routes.

What agents should do

Bootstrap resources, inspect schema and relationship guidance, adapt example queries, and then call run_read_query.

What MCP does not do

It does not accept a natural-language question and synthesize AQL for you on the server. Agents must author the AQL explicitly.

Response handling notes

  • Public landing endpoints return a simple status + data wrapper and do not accept arbitrary graph input.
  • /graph/aql-query returns the upstream graph result inside a backend wrapper that includes the effective query and bind vars.
  • MCP responses arrive as streamable HTTP event frames even when the payload itself is JSON-RPC.
  • If you are building agents, read resources and inspect schema before issuing run_read_query.
