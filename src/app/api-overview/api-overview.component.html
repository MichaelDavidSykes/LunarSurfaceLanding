Core Setup

Base Configuration

This section defines the exact request contract for the graph endpoint: base URL, method, headers, and minimal body fields.

Base URL

https://api.lunarchain.net/api/v1

Primary Endpoint

POST /graph/aql-query

Authentication

Send a bearer token when calling /graph/aql-query.

Payload Format

JSON body with one required field: query.

Required Request Fields

Method POST
URL https://api.lunarchain.net/api/v1/graph/aql-query
Required Headers
Content-Type: application/json Authorization: Bearer <token>
Required Body { "query": "<AQL string>" }
Optional Body
bind_vars: { ... } options: { ... }

Agentic Access

MCP Server

The MCP server is the agent-facing interface to the same intelligence graph. It is designed for natural-language requests, safe query planning, and bounded execution without forcing every agent to handcraft AQL.

What It Is

A streamable MCP endpoint exposed via your backend at /api/v1/graph/mcp.

Why It Exists

Lets AI agents query graph intelligence safely and consistently using standard tools instead of ad-hoc debug calls.

How To Use It

Initialize session → list tools → call query_intel for NL requests, or run_read_query for explicit AQL.
