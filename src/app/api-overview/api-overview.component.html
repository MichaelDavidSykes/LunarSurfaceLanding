Platform

Platform overview

LunarChain is a threat intelligence platform built around one shared intelligence graph. Its goal is to help organizations work with AI-enriched threat intelligence that stays connected across reports, indicators, infrastructure, actors, and other entities so teams can investigate faster, automate workflows, and support predictive analysis. The platform is composed of four main components: the frontend, the API, LunarMCP, and the underlying intelligence graph in LunarGraph.

In short

One intelligence system, multiple ways to use it

LunarChain keeps the same intelligence graph available to analysts, applications, and AI agents without splitting the underlying context into separate systems.

Agent Access

MCP workflow

LunarMCP gives agents a controlled way to understand the intelligence graph before they query it. The sequence matters: bootstrap context first, execute AQL second.

Expected sequence

  1. Initialize a session and keep the returned session id.
  2. Read resources and inspect schema before querying.
  3. Run explicit read-only AQL through run_read_query.

Flow

How agent access is meant to work

01

Connect

Initialize the MCP session over streamable HTTP and keep the returned mcp-session-id.

02

Bootstrap

Read the bootstrap, schema, alias, and ontology resources before you write any AQL.

03

Inspect

Use schema and relationship tools to confirm the live intelligence graph shape and choose strong pivots.

04

Query

Only then run explicit, bounded read-only AQL through run_read_query.

Notes

Response handling

  • Public landing endpoints return a simple status + data wrapper.
  • /graph/aql-query returns the upstream intelligence graph result inside a backend wrapper with the effective query and bind vars.
  • MCP responses arrive as streamable HTTP event frames even when the payload itself is JSON-RPC.
  • If you are building agents, read resources and inspect schema before issuing run_read_query.

AQL

AQL playbook

AQL, or Arango Query Language, is the query language used to read and traverse the intelligence graph stored in LunarGraph. Use it when you need precise filtering, intelligence graph traversals, or custom result shapes that go beyond fixed API routes or higher-level helpers.

Think of it this way

AQL is the lowest-level read path for the intelligence graph. Start here when you need exact control over what the intelligence graph returns.
